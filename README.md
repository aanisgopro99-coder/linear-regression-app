# Linear Regression Platform

A Windows desktop application for exploring linear regression. The repository contains the Python application entry point and downloadable executable releases.

## Download

The latest Windows build is available in [Release v2.1](https://github.com/aanisgopro99-coder/linear-regression-app/releases/tag/v2.1):

- `LinearRG.exe` — latest build from the current application source.

Older builds remain available in the release history.

## Source

- `main.py` — tracked Python application entry point.

## Notes

The executable is a Windows build. Download and run it on a compatible Windows system.
